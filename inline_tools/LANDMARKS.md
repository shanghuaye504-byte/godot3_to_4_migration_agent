## 当前边界

`read` 和 `grep` 已实现；路径归一化位于 `_workspace.py`。这两项保持只读，后续主要修 `editandfixguard` 并由宿主绑定工作区。一次修复不应顺带更改读工具已有的路径边界。

工具本身不负责创建工作区、首次 Git 提交、UID 规范化或场景冻结；这些属于 L0。模型只有受控工具，没有 Bash、裸 Git 或自由 Godot 命令。

## 跨包联动
